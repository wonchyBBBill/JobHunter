# Application Rules

## Mode

Selected mode: Volume (default). Promote a specific high-fit role to Precision when asked.

## First Trial Boundary

Selected first trial boundary: **Lead finding only**. Find, screen, classify, and update the dashboard. Do not open application flows or submit.

## Prioritize

- Role families: AI application / LLM engineer, RAG, Agent engineering, applied ML with Python.
- Titles: AI应用开发, LLM/RAG engineer, Agent engineer, AI applications engineer, graduate / 校招 / junior / 应届.
- Level: 2026 new graduate / bachelor-eligible. HKU is an overseas university — some 2027 campus windows still include overseas 2026 grads.
- Freshness: last 24–48 hours first; keep strong campus cycles that are still open even if posted earlier.
- Locations: Shanghai, Hong Kong.
- Skills fit: RAG, PEFT/LoRA, Python, evaluation/guardrails, cross-border coordination.

## Consider

- Stretch algorithm / pretrain / Megatron-vLLM roles if campus-eligible.
- Location ambiguity (Shanghai vs other China cities).
- Graduate programs whose location is Singapore / Malaysia / US.

## Skip

- Titles requiring 2+ years production experience unless the user asks to stretch.
- 2027-届-only postings that exclude 2026-08 graduates (and do not have an overseas-grad exception).
- Closed / 职位已下线 / Position Closed official pages.
- Internships that require a current Master's student.
- Chip design (IC/FPGA) unless requested.

## Hand Off to User

- Work authorization, sponsorship, compensation, relocation.
- Whether to treat Huawei 2027 海外高校 window as in-scope.
- Whether Singapore / Penang graduate programs are acceptable.

## Status Classification

- `Pending`: worth later review or application, no known high-impact blocker.
- `Needs user`: missing user-owned fact (here: relocation).
- `Skipped`: does not match rules or not worth applying.
- `Blocked`: attempted workflow could not safely proceed.
- `Submitted`: unused in this trial.
